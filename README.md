# ARK-09 // Cold Horizon

A slow, atmospheric browser game. You are the ship mind of a colony ark, waking alone in the dark with 10,000 sleepers in the hold and no memory of how you got here.

**Play:** https://shinobi163.github.io/cold-horizon/

- `index.html` — Act 0, the current vertical slice (about 5 minutes)
- `classic.html` — the original ARK-09 idle prototype

Everything is a single HTML file with no build step. Progress saves in your browser.

## Run locally

```
node serve.js
```

Then open http://localhost:8766. Add `?reset` to start over, or `?speed=10` to playtest faster.
